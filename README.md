# Byte Replacer - Замена байтов в файлах

## Описание
Программа для замены байтовых последовательностей в файлах с потоковой обработкой.

## Возможности
- Замена байтовых последовательностей произвольного размера
- Поддержка нулевых байтов (через hex-формат)
- Обработка файлов блоками (размер задаётся при компиляции)
- Эффективное использование памяти (не более 4*N байт)
- Чтение каждого байта только один раз

## Сборка проекта

### Требования
- CMake 3.10+
- Visual Studio 2019/2022 или MinGW

### Сборка с CMake
```bash
mkdir build
cd build
cmake -G "Visual Studio 16 2019" -DBLOCK_SIZE=4096 ..
cmake --build . --config Release
